# 🗺️ Roadmap Generation Engine

## 1. Dynamic 6-Month Curricula Synthesis
Located in `backend/app/ai/roadmap_generator.py`, the engine generates an ordered 6-month learning path tailored to the candidate's specific missing skills.

### Standard Phase Hierarchy:
1. **Month 1**: *Core Foundations & Syntax Mastery* — Language specifications, data structures, memory management.
2. **Month 2**: *Architecture, Frameworks & Tooling* — Multi-tier CRUD, secure authentication, API contracts.
3. **Month 3**: *Data Persistence, Caching & Performance* — SQL optimization, Redis caching, latency profiling.
4. **Month 4**: *Cloud, Microservices & Containerization* — Docker packaging, CI/CD pipelines, container runtime.
5. **Month 5**: *Production Capstone Development* — End-to-end full-scale project addressing detected skill gaps.
6. **Month 6**: *Interview Preparation & Portfolio Finalization* — System design mocks, behavioral STAR stories, ATS resume polish.
