# 🧪 Testing Strategy & Philosophy

CareerAI maintains a comprehensive test suite covering authentication, profiling, psychometrics, recommendation algorithms, resume parsing, and chat streaming.

## 🧭 Testing Documentation Directory
- [Unit Testing](./UNIT_TESTING.md) — Isolated tests for scoring logic, feature normalization, and utilities.
- [Integration Testing](./INTEGRATION_TESTING.md) — Service-layer interactions with async database sessions.
- [API Testing](./API_TESTING.md) — End-to-end HTTP endpoint tests using FastAPI `AsyncClient`.
- [AI Testing](./AI_TESTING.md) — Validation of resume parsing heuristics and assistant fallbacks.
- [Security Testing](./SECURITY_TESTING.md) — Authentication bypass prevention and unauthorized route checks.
- [E2E Testing](./E2E_TESTING.md) — Full candidate journey from registration to roadmap completion.
