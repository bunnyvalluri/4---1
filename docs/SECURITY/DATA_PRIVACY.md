# 🔒 Data Privacy & GDPR Compliance

- **Right to Rectification**: Candidates can update their bio, skills, and academic history at any time.
- **Right to Erasure**: Deleting a user account cascades to all associated profiles, user skills, resume analyses, and chat histories via database cascade rules (`onDelete: Cascade`).
- **Data Minimization**: CareerAI only collects attributes necessary for generating career recommendations.
