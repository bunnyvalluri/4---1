# 📄 Resume Optimization Guide

## 1. Creating an ATS-Compliant Resume
- **File Format**: Submit `.pdf` or `.docx` files with selectable text (no scanned images).
- **Layout**: Single-column layouts parse with highest fidelity.
- **Headers**: Use standard headers: `Experience`, `Education`, `Technical Skills`, `Projects`.

## 2. The Google XYZ Formula
Format every bullet point as:
$$\text{Accomplished } [X] \text{ as measured by } [Y] \text{ by doing } [Z]$$

*Weak Example*: "Responsible for building the backend database."  
*Optimized Example*: "Architected async PostgreSQL data layer with SQLAlchemy, reducing query latency by 45% for 100K daily requests."
