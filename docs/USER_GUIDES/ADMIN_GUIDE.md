# 🛡️ Administrator Operations Manual

Guidelines for platform administrators managing CareerAI.

## 1. Accessing the Admin Console
- Log in with an administrative account (`role == ADMIN`).
- Navigate to `/admin`.

## 2. Platform Telemetry & Analytics
- Monitor user registration velocity and daily active sessions.
- View assessment score distributions and pass rates.
- Inspect top-recommended careers to assess candidate market trends.

## 3. Managing Catalog Data
- Add new careers, prerequisite skills, and salary expectations.
- Update the aptitude question bank and benchmark expectations.
