# 🧠 Psychometric Assessment Guide

## 1. Assessment Overview
The diagnostic aptitude assessment evaluates cognitive aptitude across 5 core categories:
1. **Logical Reasoning**: Syllogisms, deductive logic, and conditional inferences.
2. **Quantitative Ability**: Numerical models, percentages, and data interpretation.
3. **Analytical Reasoning**: Graph patterns, sequences, and complexity.
4. **Verbal Ability**: Technical comprehension, grammar, and articulation.
5. **Problem Solving**: Engineering architecture dilemmas and edge-case mitigation.

## 2. Tips for Candidates
- Allocate 25 uninterrupted minutes.
- All questions carry equal weight; no negative marking for incorrect guesses.
- Results instantly update your composite career match recommendations.
