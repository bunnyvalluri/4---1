# 🔬 Machine Learning Subsystem

The ML subsystem provides explainable, reproducible scoring for career matching, semantic interest mapping, and feature extraction.

## 🧭 Subsystem Directory
- [Features Matrix](./FEATURES.md) — Raw input features, domains, and bounds.
- [Feature Engineering](./FEATURE_ENGINEERING.md) — Normalization, TF-IDF vectorization, and category encoding.
- [Scoring Model](./SCORING_MODEL.md) — Detailed mathematical formulation of the composite match score.
- [Model Evaluation](./MODEL_EVALUATION.md) — Validation metrics, distribution analysis, and fairness tests.
- [Future ML Improvements](./FUTURE_ML_IMPROVEMENTS.md) — Supervised ranking models, collaborative filtering, and embeddings.
